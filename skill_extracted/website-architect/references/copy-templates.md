# Website Copy Templates by Type

Use during Stage 8 to tailor tone, headlines, and CTAs to the specific website type.

---

## Tone Guide by Website Type

| Website Type | Tone | Voice | Avoid |
|---|---|---|---|
| E-commerce / Shop | Friendly, benefit-focused | "You'll love..." | Corporate jargon |
| SaaS / Tool | Clear, confident, outcome-focused | "Save 3 hours a week" | Vague promises |
| Portfolio / Freelance | Personal, warm, credible | "I help X do Y" | Passive voice |
| Marketplace | Trustworthy, community-first | "Join thousands of..." | Salesy pressure |
| Community / Forum | Welcoming, inclusive | "A place for people who..." | Exclusionary language |
| Blog / Content | Conversational, expert | "Learn how to..." | Clickbait |
| Booking / Services | Reassuring, professional | "Easy. Fast. Done." | Overpromising |
| Non-profit | Inspiring, mission-driven | "Together we can..." | Guilt-tripping |
| Restaurant / Local | Warm, sensory, local | "Fresh. Made with love." | Corporate feel |

## Headline Formulas by Goal

### Goal: Get signups
- "[Number] [target users] already use [Brand] to [benefit]"
- "The [adjective] way to [do the main thing]"
- "[Do X] without [the painful thing they currently deal with]"
- "Finally, a [product type] that [solves the key frustration]"

### Goal: Sell products
- "[Product] that [specific benefit]"
- "Get [desired outcome] in [timeframe]"
- "The [superlative] [product] for [target customer]"

### Goal: Build community
- "A home for people who [shared interest or identity]"
- "Connect with [number]+ [type of people] who [shared goal]"
- "You don't have to [struggle] alone"

### Goal: Book services
- "Get [result] — without [hassle]"
- "[Service] that works around your schedule"
- "From [starting point] to [end result] in [timeframe]"

## CTA Button Copy by Action

| Action | Strong CTAs | Weak CTAs (avoid) |
|---|---|---|
| Sign up | "Get Started Free", "Create My Account", "Join Free" | "Submit", "Click Here", "Sign Up" |
| Buy | "Get [Product]", "Shop Now", "Add to Cart" | "Buy", "Purchase" |
| Learn more | "See How It Works", "Watch Demo", "Explore Features" | "Learn More", "Click Here" |
| Book | "Book My Spot", "Schedule a Call", "Reserve Now" | "Book", "Submit" |
| Download | "Download Free", "Get the Guide", "Grab My Copy" | "Download", "Get" |
| Contact | "Send a Message", "Let's Talk", "Get in Touch" | "Contact", "Submit" |

## Page Copy Starters by Page Type

### Home Page
Structure: Hero → Problem → Solution → Features → Social proof → Pricing → Final CTA

Hero formula:
- Headline: The ONE thing your site does, in plain English
- Subheadline: Who it's for + what they get
- CTA: The first action you want them to take

### About Page
Structure: Origin story → Mission → How it works → Team (if applicable) → CTA

Opening line formulas:
- "We built [Brand] because we were frustrated with [problem]."
- "[Brand] started when [founder] realized [insight]."
- "Every [target user] deserves [benefit]. That's why we built [Brand]."

### Pricing Page
Structure: Headline → Plans → Feature comparison → FAQ → Trust signals → CTA

Headline formulas:
- "Simple pricing. No surprises."
- "Start free. Scale when you're ready."
- "Plans that grow with you."

FAQ must-haves:
- "Can I cancel anytime?" → Yes, no long-term contracts
- "Is there a free trial?" → Answer honestly
- "What payment methods do you accept?" → Cards, PayPal, etc.
- "What happens when I hit my limit?" → Explain upgrade path

### Contact Page
Keep it minimal. Include:
- One-line invitation: "Got a question? We'd love to hear from you."
- Response time expectation: "We typically reply within 24 hours."
- Alternative contact: email address (even if there's a form)

## Email Copy Starters

### Welcome Email
Subject line formulas:
- "Welcome to [Brand] — you're in!"
- "Your [Brand] account is ready 🎉"
- "One thing to do right now in [Brand]"

Opening line: "Hey [first name]! You just made a great decision." (warm, personal)
Body structure: Welcome → What they can do now → One clear next step → Support link
Sign-off: A real name, not "The [Brand] Team" — feels more human

### Transactional Emails (order confirmed, booking confirmed, etc.)
Subject: "[Action] confirmed — here's what's next"
Keep it short. Confirm what happened, what they need to know, and what happens next.
Include: order/booking number, date, amount (if payment), next steps.

### Password Reset
Subject: "Reset your [Brand] password"
Body: Simple. One link. Expiry time. "If you didn't request this, ignore this email."
Never include the password in the email.

## 404 Page Copy (Make It Human)

**Good:**
- "Looks like this page went on vacation. Let's get you back home."
- "Hmm, we can't find that page. It might have moved or never existed."
- "404 — Page not found. But the good news is, everything else is working great!"

**Bad:**
- "Error 404: The requested resource could not be located."
- "Page Not Found."

Always include a link back to the home page and, if possible, a search box.

## Empty State Messages (When There's No Data Yet)

The empty state is a golden opportunity to guide the user to their first action.

Formula: [What's missing] + [Why it's OK] + [What to do next]

Examples:
- Products: "No products yet. Add your first one and it'll show up here!"
- Orders: "You haven't placed any orders yet. Browse our store to find something you love."
- Messages: "No messages yet. Start a conversation!"
- Posts: "It's quiet here. Be the first to post something!"
- Search results: "No results for '[query]'. Try different keywords or browse all [category]."
